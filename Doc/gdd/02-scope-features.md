# [ชื่อเกม] — Scope & Feature List

## Unique Selling Point (USP)

1. มี theme เป็นโลกล่มสลายหลังจากเกิด rapture ทำให้หนุษย์ที่มีบาปและถูกแสงแดดเกิดการกลายพันธ์
2. ผู้เล่นสามารถเลือกที่จะสำรวจห้องหรือพื้นที่ ที่อยากสำรวจเองได้
3. ใช้ระบบเวลาเพื่อจำกัดการสำรวจของผู้เล่นเพื่อให้ผู้เล่นตัดสินใจมากขึ้น

## In Scope — สิ่งที่ "จะทำ" ในภาคการศึกษานี้

| # | Feature           | Priority | หมายเหตุ                                                                                   |
| - | ----------------- | -------- | -------------------------------------------------------------------------------------------------- |
| 1 | Base Management   | Must     | ทำให้อัปเกรดฐานได้                                                               |
| 2 | Map Management    | Must     | ทำให้ผู้เล่นเลือกจุดต่างๆที่อยากสำรวจได้                   |
| 3 | Exploration       | Must     | ระบบในการสำรวจ,ตัดสินใจและ combat                                         |
| 4 | Sprite Sheet      | Must     | ทำให้เกมมี visual                                                                        |
| 5 | Icons             | Must     | ทำให้มีปุ่ม interact                                                                    |
| 6 | Events            | Should   | ทำให้เกมมีเนื้อเรื่องและมีทางเลือกให้ผู้เล่นเลือก |
| 7 | Weapon Management | should   | ทำให้ผู้เล่นสามารถเลือกอาวุธก่อนไปได้                         |

## Out of Scope — สิ่งที่ "จะไม่ทำ"

- ระบบเกราะ

## Risks & Assumptions

| ความเสี่ยง                       | ผลกระทบ                 | แผนรับมือ |
| ------------------------------------------ | ------------------------------ | ------------------ |
| ไม่เคยทำระบบสร้างบ้าน | อาจจะทำออกมาช้า | ลองทำ         |
